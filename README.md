# RaktSetu 🩸 — Real-Time Blood & Emergency Donor Matching

Hospitals post urgent blood requests and nearby eligible donors are alerted instantly.

**Live app:** (add your Vercel link)  
**API:** (add your Render link)

## Tech stack
React + Vite + Tailwind CSS, Redux Toolkit, Context API, Node.js + Express, MongoDB Atlas + Mongoose, JWT + bcrypt, Socket.IO, Docker + Docker Compose, GitHub Actions, Vercel, Render.

## Features
- Responsive UI (Home, Login, Dashboard, Chat)
- REST API with validation, rate limiting and security headers
- JWT authentication with User/Admin roles
- Real-time chat and live new-request alerts (WebSockets)
- Dockerized frontend and backend, run together with Docker Compose
- CI/CD with GitHub Actions, auto-deployed to Vercel and Render
- Frontend: http://localhost:5173, API: http://localhost:5001 (needs a `backend/.env`, see `.env.example`).
